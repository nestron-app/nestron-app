<h1 align="center">Nestron</h1>
<p align="center"><strong>A home for your data platform.</strong></p>

Nestron is an infrastructure project for teams building and operating data platforms.

We are developing reusable Azure templates, explicit platform capability contracts and independently deployable runtime services. The design supports creating a platform, connecting to one, or discovering and reusing existing resources.

Built alongside **Ingestron**, with independent use by platform engineers and SREs in mind.

**Status: in development.** Templates, services and package integrations are being designed and qualified; they are not presented here as released capabilities.

Brand sources are maintained privately. This profile uses the account's published avatar.
